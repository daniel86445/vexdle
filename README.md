# VEXdle

A daily rngdle-style roll game for VEX V5RC. Roll 6 slots of V5RC/VURC parts, packs, kits, fields, game elements and manuals, hit combos, earn XP, and win an award.

- `js/items.js` is generated by `python3 tools/build_items.py` (data from vexrobotics.com, Nov 2026)
- `js/combos.js` has all combo rules
- `js/combo-xp.js` is generated by `node tools/calibrate.js 500000`. It gives each combo a fixed XP value from its rarity and sets the award tier cutoffs.
- Open `index.html?debug` for unlimited test rolls (nothing saved)

Not affiliated with VEX Robotics or the REC Foundation.
